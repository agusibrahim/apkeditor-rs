🔐 Signing Options

File must contain both PRIVATE KEY and CERTIFICATE.

Convert JKS to P12 (Standard):

keytool -importkeystore -srckeystore app.jks -destkeystore app.p12 -deststoretype PKCS12

Convert P12 to PEM (No Password):

openssl pkcs12 -in app.p12 -nodes -out app.pem
